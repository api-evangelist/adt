# ADT

> ADT LLC is a provider of monitored security, interactive home and business automation, and
> related monitoring services for residential and small-business customers across the United
> States and Canada. Its products include professionally monitored alarm systems, video
> surveillance, access control, and smart-home automation through the ADT+ platform.

**ADT does not publish a public developer API.** As of 2026-08-30 there is no ADT developer
portal, no published API reference, and no machine-readable contract (OpenAPI, AsyncAPI,
GraphQL SDL, WSDL or .proto) served on any ADT host. Integrations are arranged as named
partnerships — historically the Pulse and Canopy partner APIs, more recently by building on
Google's Home APIs — rather than through self-service developer onboarding.

Generated by API Evangelist from apis.yml and the probe artifacts in this repository.
This file is API Evangelist's summary of ADT, not a document ADT published.

## What ADT actually serves to machines

- [OpenID Connect discovery](https://auth.adt.com/.well-known/openid-configuration): the only
  machine-readable document ADT serves anonymously. It describes the identity provider behind
  ADT's customer portal (issuer `https://auth.adt.com`, Salesforce Experience Cloud), with
  authorization, token, userinfo, revocation, introspection and dynamic client registration
  endpoints, RS256 ID tokens and DPoP support. It authenticates ADT customers into ADT's own
  web application; it is not a developer-API authorization server.
- `api.adt.com`: a live ADT host. TLS completes against a Sectigo OV certificate issued to
  `ADT LLC` (CN=api.adt.com, valid 2026-06-25 to 2027-01-09), so ADT actively maintains it,
  but the origin returns zero bytes to any anonymous HTTP request. Nothing about its
  interface can be stated.

## What is not there

- No `developer.adt.com` or `developers.adt.com` — neither hostname resolves.
- No OpenAPI, AsyncAPI, GraphQL schema, WSDL or Protobuf on any ADT host.
- No MCP server, hosted or packaged. No A2A agent card.
- No public API status page (`status.adt.com` does not resolve).
- No published rate limits, deprecation policy, error catalog or developer pricing.
- No first-party SDK in any package registry. The only ADT client libraries that exist
  (`pyadtpulse` on PyPI, `adt-pulse` on npm) are community reverse-engineerings of the legacy
  ADT Pulse customer portal, not ADT software.
